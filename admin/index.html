How it works

  1. Create a course for each subject / section you teach. Each gets its own join code.
  2. Share the join code. Students register, then enter the code on their dashboard.
  3. After each class, publish a quiz. Students answer and see their score immediately.
  4. Close the quiz when time is up (or set an automatic close time). Students who missed it score zero.
  5. End of semester: the Gradebook totals every student's marks, scaled to your weight, ready to export as CSV.

New Course

If quizzes are worth, say, 10 marks of the final grade, enter 10. Each student's semester percentage is scaled to it (85% → 8.5 / 10).
