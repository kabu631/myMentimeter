How Daily Class Quizzes Work

  • Class Belonging: Each quiz is tied to a specific class number (Class 01 through Class 35).
  • Single Attempt Rule: Students can only attempt each published quiz once. Database constraints strictly prevent double submissions.
  • Anti-Cheat Verification: Correct answers are never sent to student browser DevTools. Scoring happens inside PostgreSQL via the submit_quiz stored procedure.
  • Draft vs. Published: Keep quizzes in Draft status while writing questions. Click Publish right after the class lecture so students can take it.

Granting Teacher Permissions

When faculty members register an account, they start with the default student role for security. To elevate a faculty account to teacher, run this in your Supabase SQL Editor: 

UPDATE public.profiles 
SET role = 'teacher' 
WHERE email = 'YOUR_TEACHER_EMAIL@college.edu';
